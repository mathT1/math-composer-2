# Math-Composer 2 — 소리의 수학

고등학교 2학년 「대수」 융합 수업용 웹앱. 태블릿으로 실제 소리를 녹음해 측정하고, 음계 속 비율을 지수·로그·삼각함수·수열로 설명하고, 자기 음계와 자기 음색으로 곡을 짓는다.

- 설치와 계정이 필요 없다. 주소를 한 번 열면 그 뒤에는 인터넷 없이 동작한다.
- 녹음한 소리는 기기 밖으로 나가지 않는다. 앱은 자기 주소 밖으로 아무 요청도 하지 않는다.
- 현재 개발 중이며, 지금 배포된 것은 태블릿 동작을 확인하는 기기 점검 페이지다.

## 개발

```
npm install
npm run dev     # 개발 서버
npm test        # 계산 로직 테스트
npm run e2e     # 브라우저 테스트 (가짜 마이크)
npm run build   # dist/ 에 빌드
```
